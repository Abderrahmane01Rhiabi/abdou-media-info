AbdouMediaFinder

A Personal Media Discovery Tool

AbdouMediaFinder is a personal application developed for local use. Its purpose is to help its developer discover publicly available visual content on Pinterest, including images and videos, for research and personal video editing projects.

Main Features

  • Discover publicly available Pinterest Pins.
  • Retrieve available image information and media URLs through authorized API access.
  • Explore content for visual inspiration.
  • Organize media references for personal video editing projects.

Application Access

This application is currently under development and runs locally on the developer's computer. It is intended exclusively for personal use and is not distributed to the public.

Pinterest API

This application may use the official Pinterest API to access Pinterest content, subject to Pinterest's API permissions, access restrictions, and developer terms.
